# Development guide

The application lives in `code/gremlin-bot`. It is an ES module project requiring Node.js 22.12 or later.

- Install locked dependencies with `npm ci`.
- Run `npm test` before submitting code changes.
- Run `npm run check` after configuring credentials to verify live services.
- Keep generated logs, credentials, user memory and dependency directories out of Git.
- Preserve voice timing, transcript privacy, spending limits and provider content policies.

See the application README for setup and deployment instructions.
