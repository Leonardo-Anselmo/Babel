Small models the local Whisper server runs on the processor (not the graphics card).

smart-turn-v3.2-cpu.onnx
  Smart Turn v3.2, an end-of-turn model: from the sound of the last few seconds,
  is the speaker done? Taken unchanged from the pipecat-ai package (version 1.14.0).
  Its feature code in server.py (whisper_log_mel) follows pipecat's numpy version
  of the Whisper feature extractor.

melspectrogram.onnx, embedding_model.onnx
  The sound front end for wake word models (a mel spectrogram and Google's speech
  embedding), taken unchanged from the livekit-wakeword package (version 0.3.0),
  which builds on openWakeWord. Licensed under the Apache License, Version 2.0:
  https://www.apache.org/licenses/LICENSE-2.0

<name>.onnx (for example babel.onnx)
  The bot's own wake word model, trained for its name with livekit-wakeword
  (Apache License 2.0) on synthetic voices. The scoring code in server.py
  (WakeWord) follows livekit-wakeword's inference code.
